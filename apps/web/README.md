# `@syncforge/web`

Next.js App Router application for the SyncForge workspace shell.

## Commands

```sh
pnpm --filter @syncforge/web dev
pnpm --filter @syncforge/web typecheck
pnpm --filter @syncforge/web test
pnpm --filter @syncforge/web build
```

The current routes establish the product shell only. Project creation, settings,
authentication, canvas behavior, and API integration belong to later tasks.
